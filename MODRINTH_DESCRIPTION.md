# Create: Overpressure

## Русский

**Create: Overpressure** - небольшой аддон для Create, добавляющий удобную пневматическую перевозку предметов. Соединяйте хранилища трубами, прокладывайте линии с плавными поворотами и ускоряйте их кинетическими насосами.

### Скриншот: готовая пневматическая линия
`[Вставить широкий скриншот: два сундука или машины Create, соединённые трубами, с одним плавным изгибом.]`

### Что добавляет мод

- **Пневматические трубы** для переноса предметов между контейнерами.
- **Изогнутые участки** для аккуратных поворотов линии.
- **Пневмо-экстрактор**: забирает предметы из контейнера или принимает их в него. Поддерживает фильтр Create и отключается сигналом редстоуна.
- **Насос предметов**: ускоряет движение по трубе, расходуя кинетическую нагрузку. Чем выше скорость вращения, тем быстрее работает линия.

### Скриншот: экстрактор с фильтром и редстоуном
`[Вставить скриншот: экстрактор у сундука, фильтр Create в слоте и активный редстоун-сигнал.]`

### Скриншот: насос в кинетической сети
`[Вставить скриншот: насос в центре трубы, подключённый к шестерне Create; очки инженера показывают скорость переноса.]`

Все рецепты форменные. В игре есть Ponder-сцены, объясняющие изгибы труб, экстракторы, фильтры, редстоун и насосы.

### Требования

- Minecraft 1.21.1
- NeoForge
- Create 6.0.10

## English

**Create: Overpressure** is a small Create addon that adds practical pneumatic item transport. Link inventories with tubes, route lines through smooth turns, and speed them up with kinetic pumps.

### Screenshot: completed pneumatic line
`[Add a wide screenshot: two chests or Create machines connected by tubes, including one smooth curve.]`

### Features

- **Pneumatic Tubes** move items between inventories.
- **Curved sections** keep tube routes tidy around corners.
- **Pneumatic Extractors** pull items from an inventory or insert them into one. They support Create filters and can be disabled with redstone.
- **Item Pumps** speed up tube transport while consuming kinetic stress. Faster rotation means faster item movement.
