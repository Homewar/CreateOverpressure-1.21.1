
# Create: Overpressure

Create: Overpressure adds pneumatic item transport to Create.

## Features

- Pneumatic tubes with smooth curved sections.
- Pneumatic extractors for pulling from and inserting into inventories.
- Extractor filters and redstone control.
- Kinetic item pumps that speed up transport and consume stress capacity.
- Create Ponder scenes and Engineer's Goggles transport-speed readout.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.233 or compatible
- Create 6.0.10

## Installation

Install Create and Create: Overpressure into the `mods` folder of the same NeoForge profile.
