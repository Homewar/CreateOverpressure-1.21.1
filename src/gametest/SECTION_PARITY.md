# Сравнение старых и самостоятельных изгибов

Проверены `CurvaturePneumaticTubeBlock`, взаимодействия `PneumaticTubeBlock`,
`TubeNetworkPathfinder`, `TubeTransportManager` и соответствующие реализации
в пакете `tube`. Сравнение касается игрового поведения; блоки-владельцы
не возвращаются.

| Область | Старое поведение | Самостоятельные участки после исправлений |
| --- | --- | --- |
| Разрушение | Блочное событие создаёт звук и частицы | Сервер посылает событие разрушения в месте попадания по видимой трубе |
| Материалы | Выпадают обычные трубы | Возвращается `materialCost`, стопки ограничены размером предмета; добавлена обычная задержка подбора |
| Творческий режим | Разрушение цепочки могло выбрасывать соседние блоки | Материалы не дублируются; содержимое трубы сохраняется как выпавший груз |
| Ключ Create | Shift + ключ демонтирует блок | Shift + ключ демонтирует весь участок и возвращает материалы в инвентарь; переполнение обрабатывает обычный инвентарь |
| Средняя кнопка | Клонирует обычную трубу | Выбирает обычную трубу, в том числе при наведении на изгиб в воздухе |
| Белый краситель | Цвет шёл через числовое значение красителя | Оба вида труб сбрасываются в одинаковый белый цвет без оттенка красителя |
| Открытый прямой конец | Груз выходит вдоль оси без флага соединения | Поиск смешанного маршрута тоже допускает такой выход |
| Приоритет разделителя | Предпочтение ветки важнее длины маршрута | Восстановлена оценка веток до сравнения длины, включая длинную предпочтительную ветку |
| Достройка линии | Пересчитывается продолжение пути | Пересчитывается оставшийся маршрут с сохранением насоса; проверено после загрузки |
| Предметы внутри стенок | Рисуются на стадии блоковых сущностей | Груз смешанных маршрутов тоже рисуется до прозрачных стенок |
| Сохранение и миграция | Груз и внешний вид привязаны к блокам | Геометрия, цвет, свечение и груз сохраняются отдельно; миграция переносит материалы и груз |
| Геометрия и коллизия | Кривая проецируется из блоков-владельцев | Коллизия, выбор и концы принадлежат самому участку; скрытые блоки не создаются |

GameTest проверяет доставку, перезагрузку, миграцию, геометрию, взаимодействия,
возврат материалов, задержку подбора, отсутствие повторного возврата, открытый
прямой конец и приоритет разделителя. Звук, частицы и выбор средней кнопкой
требуют также визуальной проверки в клиенте; серверный GameTest их не оценивает.
